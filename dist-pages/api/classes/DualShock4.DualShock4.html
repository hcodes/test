    • connect(device?: HIDDevice): Promise<boolean>

      Opens an authorized controller, or requests one through the browser picker.

      Without a device, call this from a user interaction (such as a click). Pass a supported device from navigator.hid.getDevices() to skip the picker. Disconnect before switching devices. A device can belong to only one instance of this library at a time; conflicts reject with InvalidStateError.

    disconnect

    • disconnect(): Promise<void>

      Stops rumble and closes the current WebHID session without revoking device permission. Pending output that is waiting for transport detection rejects with an AbortError.

      If the browser fails to close a device that remains open, the active session is restored and the error is rethrown so disconnection can be retried.

      Returns Promise<void>

    readFirmwareInfo

    • readFirmwareInfo(): Promise<DualShock4FirmwareInfo | null>

      Reads DualShock 4 feature report 0xA3 and updates firmwareInfo and isClone.

      Both USB and Bluetooth controllers use this report. The firmware request times out after one second; the optional follow-up clone check uses a shorter timeout. Unsupported, timed out, or malformed reports return null so compatible third-party controllers can still be used.

      Returns Promise<DualShock4FirmwareInfo | null>
